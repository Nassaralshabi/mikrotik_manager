# 📦 نظام النسخ الاحتياطي الكامل - MikroTik Manager

## نظرة عامة

تم إضافة نظام كامل لإدارة النسخ الاحتياطية لـ MikroTik Router مع واجهة عربية متكاملة وتصميم موحد مع باقي التطبيق.

---

## ✨ الميزات الرئيسية

### 1. عرض قائمة النسخ الاحتياطية
- عرض جميع النسخ الاحتياطية الموجودة على الراوتر
- فلترة تلقائية لعرض ملفات `.backup` و `user manager database` فقط
- ترتيب النسخ حسب تاريخ الإنشاء (الأحدث أولاً)
- واجهة سهلة الاستخدام مع بطاقات ملونة

### 2. إنشاء نسخة احتياطية جديدة
- اختيار اسم مخصص للنسخة الاحتياطية
- اسم افتراضي ذكي بناءً على التاريخ والوقت
- مؤشر تقدم أثناء عملية الإنشاء
- تحديث تلقائي للقائمة بعد الإنشاء

### 3. استعادة النسخ الاحتياطية
- تحذير واضح قبل الاستعادة
- إعادة تشغيل تلقائية للراوتر بعد الاستعادة
- رسائل توضيحية للمستخدم

### 4. حذف النسخ الاحتياطية
- تأكيد قبل الحذف
- رسائل نجاح/فشل واضحة

### 5. عرض معلومات تفصيلية
- الاسم الكامل للنسخة
- النوع (ويوكس / يوزر متجر)
- الحجم بالبايتات
- تاريخ ووقت الإنشاء

### 6. حساب الوقت المنقضي
- عرض الوقت المنقضي بصيغة مفهومة
- "منذ X ثانية/دقيقة/ساعة/يوم"

---

## 🎨 تصميم واجهة المستخدم

### بطاقات النسخ الاحتياطية
تتضمن كل بطاقة:

1. **أيقونة ملونة حسب النوع:**
   - 🟣 بنفسجي: نسخ Winbox (.backup)
   - 🟢 أخضر: نسخ User Manager Database

2. **معلومات النسخة:**
   - اسم الملف مع خلفية بنفسجية فاتحة (#B39DDB)
   - حجم الملف مع أيقونة وخلفية شفافة
   - الوقت المنقضي مع أيقونة ساعة

3. **زر الخيارات:**
   - قائمة منبثقة مع 3 خيارات:
     - معلومات النسخة ℹ️
     - استعادة النسخة 🔄
     - حذف النسخة 🗑️

### الألوان المستخدمة
- **خلفية البطاقات:** `Color(0xFF3E355F)` - بنفسجي داكن
- **خلفية اسم الملف:** `Color(0xFFB39DDB)` - بنفسجي فاتح
- **أيقونة Winbox:** `Colors.purple`
- **أيقونة User Manager:** `Colors.green`

## 🔌 أوامر MikroTik API المستخدمة

### 1. جلب قائمة الملفات
```dart
await client.talk(['/file/print']);
```

### 2. إنشاء نسخة احتياطية
```dart
await client.talk([
  '/system/backup/save',
  '=name=backup_01-11_10-30',
  '=dont-encrypt=yes',
]);
```

### 3. استعادة نسخة احتياطية
```dart
await client.talk([
  '/system/backup/load',
  '=name=backup_01-11_10-30.backup',
]);
```

### 4. حذف نسخة احتياطية
```dart
await client.talk([
  '/file/remove',
  '=numbers=backup_01-11_10-30.backup',
]);
```

## 📱 كيفية الاستخدام

### 1. الوصول إلى النظام
من الشاشة الرئيسية، اضغط على بطاقة **"النسخ الاحتياطي"** 

### 2. إنشاء نسخة جديدة
1. اضغط على الزر العائم **"إنشاء نسخة جديدة"**
2. أدخل اسماً للنسخة (أو استخدم الاسم الافتراضي)
3. اضغط **"إنشاء"**
4. انتظر حتى تكتمل العملية (2-5 ثواني)

### 3. استعادة نسخة
1. اضغط على بطاقة النسخة المطلوبة
2. اختر **"استعادة النسخة"**
3. اقرأ التحذير بعناية
4. اضغط **"استعادة"** للمتابعة
5. سيعيد الراوتر التشغيل تلقائياً

### 4. حذف نسخة
1. اضغط على بطاقة النسخة
2. اختر **"حذف النسخة"**
3. أكد الحذف

### 5. عرض معلومات النسخة
1. اضغط على بطاقة النسخة
2. اختر **"معلومات النسخة"**

### 6. تحديث القائمة
- اسحب الشاشة للأسفل (Pull to Refresh)
- أو اضغط على أيقونة التحديث في شريط التطبيق

## ⚠️ ملاحظات مهمة

### أمان البيانات
- **النسخ غير مشفرة افتراضياً** (`dont-encrypt=yes`)
- يمكن تعديل الكود لإضافة خيار التشفير بكلمة مرور
- احفظ النسخ في مكان آمن خارج الراوتر

### الاستعادة
- **⚠️ تنبيه:** استعادة النسخة ستستبدل جميع الإعدادات الحالية
- الراوتر سيعيد التشغيل تلقائياً
- ستقطع جميع الاتصالات النشطة
- احفظ بياناتك قبل الاستعادة

### التوافق
- النسخة الاحتياطية يجب أن تُستعاد على نفس إصدار RouterOS
- نسخ User Manager Database منفصلة عن نسخ Winbox

### الأداء
- عملية الإنشاء تستغرق 2-5 ثواني عادةً
- الملفات الكبيرة قد تستغرق وقتاً أطول
- يُنصح بإنشاء نسخة احتياطية قبل أي تغيير كبير

## 🔧 التخصيص والتطوير

### إضافة ميزة التشفير
قم بتعديل دالة `_createNewBackup()`:

```dart
// بدلاً من
'=dont-encrypt=yes',

// استخدم
'=password=your_password',
```

### جدولة النسخ التلقائي
يمكن إضافة ميزة جدولة النسخ باستخدام:
- `shared_preferences` لحفظ الإعدادات
- `workmanager` لتشغيل المهام في الخلفية

### تصدير النسخ
لتصدير النسخ إلى التخزين المحلي، ستحتاج إلى:
- إعداد FTP أو HTTP على الراوتر
- استخدام مكتبة مثل `dio` للتنزيل
- `file_picker` لاختيار مكان الحفظ

### "فشل تحميل النسخ الاحتياطية"
- تحقق من اتصال الشبكة
- تأكد من صلاحيات المستخدم في MikroTik

### "فشل إنشاء النسخة"
- تحقق من المساحة المتوفرة على الراوتر
- تأكد من صلاحيات الكتابة
- جرّب اسماً مختلفاً للنسخة

### "فشلت الاستعادة"
- تأكد من توافق إصدار RouterOS
- تحقق من أن الملف غير تالف
- إذا كانت النسخة مشفرة، أضف كلمة المرور
